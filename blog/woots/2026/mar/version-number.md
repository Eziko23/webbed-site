# how my vX.Y.Z system works

i use a bit of an odd version system, so im explaining here

## vX

the first number is meant for when i rewrite my site from scratch, so far ive done this seven times (with some versions still being up for you to see!)

## vX.Y

second number is for smaller updates or when i complete everything on my sitemap at the time. this is usually accompanied with small visual changes like a wallpaper change or new font

## vX.Y.Z

final number is for bugfixes, not much else
